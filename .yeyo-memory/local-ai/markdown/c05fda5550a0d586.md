# 4521-PLN-AEE-39-70-0002-GAR Rev.00 Wiring diagrams

## Resumen

- All conductors and shields must be fitted with an insulated compression type crimp.
- References include IJB-250-D1-614, IJB-250-D1-615, XV-6-255-15 to 28, ZS-6-255-24 to 28.
- Drawing is property of ABENER TEYMASOLANA.
- Notice of Alternate Billing Cycle allows for non-standard billing cycles.
- Drawing includes area map and field junction box details.
- IJB-250-D1-617 is a field junction box.
- The drawing is for the HEX replacement wiring diagram.
- The drawing is property of Abener Teyma Solar.
- The project area is in Phase 2, Solanagila Bend, Arizona.

## Observaciones

- Text is partially obscured and contains non-standard characters.
- Drawing details are repeated on both pages.
