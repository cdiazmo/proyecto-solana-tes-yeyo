# Butterfly Valves Specifications

## Specifications

### DH45
- Class 150 FF flanged
- Size: 3" - 20"
- Material: Cast iron wafer butterfly; CI disc; coated carbon steel stem; 316 SS pin; BUNA-N seat; acetal bushing; operator 6” & under-handle, 8” & over-weatherproof gear
- Note: Valves to be furnished with provision for position locking.

### DH46
- Class 150 FF flanged (flanged - separate studs each end)
- Size: 24" - 48"
- Material: Cast iron wafer butterfly; CI disc; coated carbon steel stem; 316 SS pin; BUNA-N seat; acetal bushing; operator weatherproof gear
- Note: Valves to be furnished with provision for position locking.

### DH47
- Class 150 FF flanged (insert)
- Size: 2" - 12"
- Material: Cast iron wafer butterfly; 316 SS disc stem, epoxy coated disc; EPDM seat; acetal bushings; operator 6” & under-handle, 8” and over-weatherproof gear

### DH48
- Class 150 FF flanged (lugged body)
- Size: 3" - 36"
- Material: Cast iron lugged butterfly; 316 SS disc stems pins, epoxy coated disc; EPDM seat; acetal bushings; operator weatherproof gear

### LRH47
- Class 150 FF flanged (flanged - separate studs each end)
- Size: 44" - 120"
- Material: Rubber seated butterfly valve, carbon steel body. Class 150 flanged ends ASME B16.47 Series A, 420SS shaft with aluminum bronze disc. EPDM rubber seat. Enclosed gear actuator

### LRH48
- Class 150 FF flanged (flanged - separate studs each end)
- Size: 36" - 48"
- Material: Rubber seated butterfly valve, carbon steel body, CL150 flanged ends ASME B16.47 Series A, 316SS disc and shaft with epoxy coating. EPDM rubber seat. Enclosed gear actuator

### TFH41
- Class 150 FF flanged (insert)
- Size: 3" - 8"
- Material: DI wafer butterfly with PTFE body liner; PTFE or PFA encapsulated disc; graphite filled phenolic bearings; Viton or neoprene stem seals. Operator weatherproof gear
- Note: Valves to be furnished with provision for position locking.

### Keystone “Isolator”
- Manufacturer: Durco
