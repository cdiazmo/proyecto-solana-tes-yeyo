## Specification for Molten Salt Piping 300# (304 SS)
- **Service Range:** Pressure / Temperature - 350 PSIG / 750° F.
- **Pipe Material:** 304 SS pipe with BW fittings, CL 300 BW valves.
- **Fittings:** Sch. 40S (BE) and Sch. 80S (BE) with BW fittings.
- **Welding Electrodes:** Bare - AWS A5.9 Class ER 308, Coated - AWS A5.4 Class E 308-16, Carbon steel/stainless steel.
- **Bolts and Nuts:** Alloy steel stud bolts ASTM A-193 Grade B7 with heavy hex nuts ASTM A-194 Grade 2H.
- **Gaskets:** 304L SS, ring joint, CL 300 RTJ, ASME B16.20, oval section.

## Notes
1. Welding Electrodes: Bare - AWS A5.9 Class ER 308, Coated - AWS A5.4 Class E 308-16, Carbon steel/stainless steel, Bare - AWS A5.9 Class ER 309.
2. Deleted.
3. Weldolets preferred for tie-in locations due to realignment difficulties.
4. Pressure/temperature limited by F304 flange material; do not substitute F304L.
5. Gasket material: 304L SS only, no substitution with 304SS.
