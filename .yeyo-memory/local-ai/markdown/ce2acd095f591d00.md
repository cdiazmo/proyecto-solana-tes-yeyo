# 4521-PLN-AEE-75-63-0001 Typical Pipe Supports Standard rev03

## Resumen

- This document is a typical pipe supports standard for Abeinsa.
- It includes general notes, profiles definitions, and index of typical supports.
- The drawing covers various types of pipe supports including general shoes, variable springs, and trunnions.
- Materials used include carbon steel S 275JR G2 or similar, with specific requirements for alloy steel shoes.
- All dimensions are in inches according to ASME B36.10.
- Trunnion and shoe orientation details provided.
- Orientation examples include vertical, horizontal, and elbow configurations.
- Drawing information includes project details and signatures.
- Parameters define dimensions (H, L, A) and support options.
- Drawing includes various pipe supports and their specifications.
- Support codes include G04, G07, G08, L01, and L03.
- Parameters define support length, gap, and profile type.
