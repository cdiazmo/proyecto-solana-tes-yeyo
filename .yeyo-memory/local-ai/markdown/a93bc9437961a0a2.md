# 1950201-PPI-01 Rev01

## Resumen

- The document is an Inspection Points Program for HEX replacement TES Solana project.
- It includes details on documentation, material reception, and manufacturing processes.
- Approval by Pedro Alvarez is required for the procedure.
- ASME standards are referenced throughout the document.
- Inspection points cover various aspects like dimensional control, welding, and non-destructive testing.
- Inspección volumétrica de soldaduras de tubuladuras de proceso a fondo.
- Control dimensional de partes no presión y temporales.
- Comprobación de parámetros de soldeo.
- Inspección superficial de soldaduras a barrera de presión.
- Fabricación del haz tubular.
- Inspección visual de soldaduras de chapas de choque.
- Montaje final.
