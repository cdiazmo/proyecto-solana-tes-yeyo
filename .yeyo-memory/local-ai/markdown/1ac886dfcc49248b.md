# Drain Back Tank Support Design
## Overview
The Drain Back tank support of Solana Generating Station is designed.
## Description
The support shape and the different equipment, pipeline and valves that affect to this one are shown in the next image:
The Drain back tank support is composed by several steel profiles, by screwing connections and all is supported on the slab of pit by baseplate and anchoraged by several post-installed bolts to these one.
## Codes and Normative
- IBC 2012 International Building Code
- AISC 360-10 American Institute steel code
- ASCE 7-05 Minimum Design Loads for Buildings and Other Structures.
## Design Basis
For design purpose a static finite elements analysis have been performed using a shell elements in order to apply the different loads.
## Materials
- Steel: Structural steel W-shape: ASTM A992 (Fy=50 ksi)
- Other structural steel : ASTM A36
- Bolted connections high strength: ASTM A325 or A490
- Secondary bolts: ASTM A307
## Safety Factors and Load Combination Coefficients
- Fracture U.L.S. rolled steel: ANSI/AISC 360-05 (LRFD)
## Loads
### Dead Load
- Specific self-weight of steel elements: 490 lb /ft³
- Self-Weight of Drain tank: 6,500 lb
- Self-Weight of pump: 500 lb
- Total weight (tank + pump) is divided for Length support (4 feet) and also divide between two supports:
  - 7.000 Lb / 4 feet /2 supports = 875 Lb/ft
### Live Load
- Weight water in maximum capacity of tank: 13,000 lb
- Total weight is divided for Length support (4 feet) and also divides between two supports:
  - 13.000 Lb / 4 feet /2 supports = 1625 Lb/ft
### Wind Load
Load not applied.
### Seismic Load
To be defined the response spectrum to apply at this project; it has considered the next factors:
- Site class definition: Class D
- Ss=0.230g, S1=0,088g, Fa=1.6 Site coefficient, Fv=2.4, Sms= 0,368g, Sm1=0,212g, SDS= 0.245g, SD1=0.142g
### Thermal Load
Not applied.
### Snow Load
Not applied.
