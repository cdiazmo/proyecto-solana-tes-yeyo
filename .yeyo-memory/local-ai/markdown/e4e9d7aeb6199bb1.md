# WALL BOUNDARY REINFORCING SPLICE NOTES

**1. Bundled Bars of More Than 2 Bars (Including Splice Bar) in the Same Plane is Not Permitted. Acceptable Bundled Bar Layouts are:*
- **CS 3-BAR BUNDLE**: Splice Bar, Non-bundled Bar
- **CS 4-BAR BUNDLED**: Splice Bar

**2. Use Bar Diameter Derived from Equivalent Total Area to Determine Applicable Splice Type for Bundled Bars. See Schedule Below.**

**3. Do Not Splice More Than One Bar in a Bundle. See Splice Diagram for Acceptable Bundle Bar Splice Diagram.**

**Additional Bundled Bar Notes:*
- **CS 1" MIN.**: Minimum Clear Spacing
- **Staggered Splice**: CS NO, Staggered Bar Spacing
- **All Splices Shall Be "CLASS B" Unless Noted Otherwise.**
- **For CLASS A Splice Length See "TYPICAL STRAIGHT REINFORCING DEVELOPMENT LENGTH SCHEDULE" DEVELOPMENT TYPE "TYPICAL".**
- **Bar Location: TOP BARS - HORIZONTAL BARS WITH MORE THAN 12" OF CONCRETE CAST BELOW THE BARS. OTHER BARS - ALL VERTICAL BARS AND HORIZONTAL BARS WITH LESS THAN 12" OF CONCRETE CAST BELOW BARS.**
- **Development Type: TYPICAL: D1 - C ≥ 2db AND S ≥ 4db, D2 - ALL OTHER CONDITIONS, D3 - C < db OR S < 2db. SEISMIC: PROVIDE "SEISMIC" SPLICE FOR ALL SEISMIC SPLICES LOCATED OUTSIDE FRAME COLUMNS AND SHEARWALL BOUNDARY ELEMENTS INCLUDING DRAGS, CHORDS, DIAPHRAGM REINFORCING AND DISTRIBUTED SHEARWALL REINFORCING.**
- **Reinforcing Grade: Reinforcing Splice Length is for Grade and Reinforcing. For GRADE 75 REINFORCING MULTIPLY THE SPLICE LENGTHS IN SCHEDULE BY 1.25.**
- **Concrete: Reinforcing Splice Length Schedule is for NORMAL WEIGHT CONCRETE. FOR LIGHT WEIGHT CONCRETE MULTIPLY LENGTHS IN SCHEDULE BY 1.3.**

**NOTES:**
- **Splice Length**: Refer to Schedule Below
- **Deformed Rebar and Threaded Rod Noted as EPOXY**: Install Per Manufacturers Recommendations, See Schedule for Minimum Embedment Lengths
- **Only Non-Rebar-Cutting Drill Bits**: Use to Drill Holes in Existing Concrete, Care When Drilling
- **Drilled Holes Cleaning**: Clean Using LON Brush and Vacuum or Nylon Brush and Oil-Free Compressed Air
- **Special Inspection Required**: For Installation of All Adhesive Anchors, Inspector to Verify Embedment Length, Hole Preparation, Cleanliness, Correct Implementation of Manufacturer's Instructions
- **Drill & Epoxy**: Use Only Where Indicated on Drawings
- **Seismic Bar at a Joint**: Legend Includes CROSSTIE, SEISMIC STIRRUP, HOOPSEISMIC CROSSTIESINGLE-PIECE, HOOPSEISMIC STIRRUPSEISMIC HOOK

### Detalles generales
**Fundacones:**
- Las fundaciones no deben excavarse debajo de esta línea.
- El conducto debe estar ubicado de tal manera que las fundaciones no sean atenidas.
- La cubierta debe ser reforzada y preparada según el plan.

**Reforzamiento:**
- El reforzamiento puede ser continuo o discontinuo.
- Las uniones pueden ser de tipo "keyed cold joint" o "gálvanizado".

### Planos
**Plano de cubierta sobre nivel:**
- La cubierta debe colocarse en tiras de 60'-0" de ancho.
- El reforzamiento debe estar ubicado a una distancia máxima de 60'-0" entre uniones longitudinales y transversales.

**Plano de pared:**
- La pared debe tener un espesor mínimo de 12" y el reforzamiento debe ser proporcionado según las especificaciones del plan.

### Anotaciones adicionales
- Las uniones deben estar marcadas con una "t" para indicar la espesor de la cubierta sobre nivel.
- Las uniones de control deben estar ubicadas perpendicularmente a las uniones de construcción a una distancia máxima de 20'-0" entre ellas.
- Las uniones de control deben estar marcadas con una "b".
