# 1950801-CAL-0002.00-Calculo Estructural estructura plataforma soporte bombas de sales

## Resumen

- Este documento es un cálculo estructural orientativo para la plataforma de bombas de sales.
- Se utilizan modelos de cálculo para la estructura soporte y pasarela intermedia.
- Las cargas incluyen peso propio, tubería, viento y sísmica.
- El proyecto está en CORDOBA, España, bajo el cliente ATLANTICA y suministrado por LOINTEK.
- Las mismas combinaciones de carga se aplican tanto al rack como a la estructura soporte de las bombas de sales.
- Se realizan 3 comprobaciones: resistencia de las vigas, resistencia a pandeo y análisis de flechas máximas.
- Para el rack y la estructura soporte, la viga mecánicamente más exigida está al 34% de su capacidad.
- Las flechas admisibles superan las obtenidas en ambos modelos, lo que confirma la validez de los cálculos.
- El cálculo es susceptible a cambios en próximas fases del proyecto.

## 5 RESULTADOS

### 5.1 Rack

### 5.2 Estructura soporte y pasarela intermedia
