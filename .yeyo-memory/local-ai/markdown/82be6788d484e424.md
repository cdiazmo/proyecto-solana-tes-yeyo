# 1950801-LIS-3660-00 Rev01 Lista Valvulas General

## Resumen

- Sheet name: SPReport_Definition
- Columns include Plant Item, Representation, Drawing, and Drawing Project
- Data includes project details like Yanbu, KKSEquipmentUnitKey, and EA_KKSDrawingNumber
- Represents various valve types and their specifications
- File contains information on suppliers, drawing numbers, and technical parameters
- Tabla de conversión de NPS (inches) a ND (mm)
- NPS va desde 1/2" hasta 40"
- ND va desde 15 mm hasta 1000 mm
