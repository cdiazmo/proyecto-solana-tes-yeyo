# Soporte tuberías TES 6 MS

## Descripción del soporte
- **Isometric reference point**: Punto de referencia isométrico
- **Existing structure**: Estructura existente
- **Existing typical shoe**: Zapatilla típica existente
- **Anti-friccion plate**: Placa antifricción

## Dimensiones y especificaciones
- **A = 4.72 inch**
- **B = 4.72 inch t=1.77 inch**
- **H = 29.80 inch**
- **L = 19.68 inch**

## Materiales y elementos
- **Graphite self-lubricating, spherical plate**: Placa esférica de grafeno auto-lubricante
- **Stainless steel plate**: Placa de acero inoxidable
- **Base plate**: Placa base
- **Non-rotating trunnion**: Tronco no rotativo

## Notas
1. Coeficiente de fricción debe ser menor a 0.15
2. Elemento proporcionado por el vendedor, definir la geometría final
3. Placa de acero inoxidable de 0.07 pulgadas será sellada en la parte inferior de la zapatilla
4. La placa base será sellada a la estructura
5. Ver cargas en la lista de soportes
6. Limitación desde la base de la zapatilla
