# Engineering Standards and Practices
## Material and Installation Standards
**Job No.:** 120006
**No. Req'd.:** 1
**Project:** Solana
**Block Butterfly Valves – Plastic Ref.: PS-V313 Issue: 0 Dated : 11 Feb 08**
### Globe Valves
- **PVB1**: Class 150 threaded, ½” - 4”, Solid PVC Y-pattern globe, screwed bonnet, rising stem, PVC stem and integral seat, teflon packing, glass filled teflon disc.
- **PCF25**: Class 150 socketweld, ½” - 2”, 3” - 4”, CPVC true union ball valve, solid CPVC body, ball & stem, TFE seats and Viton “o”-ring seals.
- **PVC1**: Class 150 threaded, ½” - 4”, Solid PVC ball check, horizontal or vertical-up flow, union construction, Viton o-ring seals.
### Ball Valves
- **PCF25**: Class 150 socketweld, ½” - 2”, 3” - 4”, CPVC true union ball valve, solid CPVC body, ball & stem, TFE seats and Viton “o”-ring seals.
- **PVC25**: Class 150 socketweld, ½” - 4”, Solid PVC ball check, horizontal or vertical-up flow, double union, Viton O-ring seats, solid PVC ball & body.
### Butterfly Valves
- **PVH1**: Class 150 flanged wafer (lugged type), 4” - 8”, PVC Wafer Butterfly, PVC Body & Disc, 316 SS Shaft, TFE Shaft Bearings, Viton O-Ring Seals, Viton Seat.
### Swing Check Valves
- **PQC41**: Class 150 flanged, 2” - 8”, Polyproplylene body swing check, flanged FF, Viton seat and seal.
