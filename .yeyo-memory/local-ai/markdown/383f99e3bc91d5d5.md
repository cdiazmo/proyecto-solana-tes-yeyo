# Engineering Standards and Practices
## Material and Installation Standards
**Job No.:** 120006
**Class:** Class 300 Carbon Steel – Piping System
**Project:** Solana
**HTF Return Ref.:** PS-CS77
**Issue:** 0
**Date:** 6/14/2011

### Service Range
Maximum 350 PSIG @ 750°F. See pressure/Temperature Chart (Figure No. 1) on Page 2 of 2.

### Construction
- **Nominal Pipe Size:** 3/4, 11, 1 1/2, 22, 2 1/2, 33, thru 20, 24, 30, 36, 42
- **Pipe Material:** Carbon steel pipe, socketweld FS fittings, flanges and valves; CS buttweld fittings, lap joint and WN flanges and flanged valves.
- **Wall Thickness:** .625" and .688"

### Fittings
- **Nipple:** Use pipe fittings for reduction use inserts. For full size through two sizes smaller use tee. For greater size change use sockolet or weldolet as required.
- **Flanges:** FS CL 300, SW, RF, ASTM A -105 FS CL 300, RF, weld neck, ASTM A -105, ANSI B16.5
- **Bolting:** Alloy steel stud bolts ASTM A -193 Grade B7 with heavy hex nuts ASTM A -194 Class 2H
- **Gasket:** 0.175" thick 304 SS and flexible graphite, spiral wound gasket, CL 300 API 601 (compresses to 1/8" thickness) MSS -SP44

### Valves
- **Gate Valve:** FA40 - CL 600/800 SW, FA56 - CL 300 buttweld
- **Globe Valve:** FB40 - CL 600/800 SW, FB56 - CL 300 buttweld
- **Triple Offset:** FH56 – CL 300 buttweld
- **Check Valve:** FC39 - (inclined piston check) CL 600/800 SW, FC56 - (swing check) CL 300 buttweld

### Notes
1. All piping shall comply with ANSI B31.3 basic code unless otherwise specified.
2. Sockolets or weldolets are preferred for use at tie-in locations.
3. Flanges shall be used only where required to mate with equipment nozzles. All other joints shall be buttweld connections.
4. All pipe & fittings to be internally cleaned per spec 4521-ESP-ANC-00-61-PS010.
5. At a minimum, all shop and field root pass welds shall be done using TIG welding process.
6. All shop welds to receive 5% X-ray. All field welds to receive 100% X-ray.
7. All pipe shall be installed “clean”.
