## Specification for Chemical Feed Piping (Chelating Agents)
### Application
This specification is intended for chemical feed piping only.

### Service Range
- **Pressure / Temperature:**
  - 1200 PSIG / 200°F
  - 830 PSIG / 600°F
  - 1055 PSIG / 300°F
  - 805 PSIG / 700°F
  - 940 PSIG / 400°F
  - 795 PSIG / 800°F
  - 875 PSIG / 500°F

### Construction
- **Pipe:** 304L SS pipe with SW fittings, CL 600 flanged valves (preferred) or CL 600 SW valves.
- **Fittings:** CL 3000 socketweld Sch. 40(BE) Sch. 80(BE)

### Nominal Pipe Size and Schedule
| Nominal Pipe Size | 1/2 | 3/4 | 1 | 1 1/2 | 2 | 3 | 4 | 6 | 8 |
|-------------------|-----|-----|---|-------|---|---|---|---|---|
| Pipe Schedule     | 80 (PE) Sch. 40 (BE) Sch. 80 (BE) |

### Material and Welding
- **Pipe:** 304L fusion welded SS in accordance with ASTM A-312, Grade TP304L
- **Fittings:** Type 304L SS ASTM A-182 Grade F304L, ANSI B16.11 304L SS ASTM A-403 Grade WP304L, buttweld, ANSI B16.11
- **Welding Electrodes:** Bare - AWS A5.9 Class ER 308, Coated - AWS A5.4 Class E 308-16, Carbon steel/stainless steel, Bare - AWS A5.9 Class ER 309

### Fittings and Valves
- **Gate Valve:** TA62 - CL 600 RF flanged
- **Globe Valve:** TB37 - CL 600 SW
- **Lift Check Valve (Hor. Use):** TC39 - CL 600 SW

### Notes
1. **Welding Electrodes:** Bare - AWS A5.9 Class ER 308, Coated - AWS A5.4 Class E 308-16, Carbon steel/stainless steel, Bare - AWS A5.9 Class ER 309.
2. **Socketweld connections (at valves):** Only at locations where temperatures are 500°F or less.
3. **Sockolets or weldolets:** Preferred for tie-in locations due to realignment difficulties.
4. **Pressure / temperature allowed:** Limited by F304 flange material; do not substitute F304L.
