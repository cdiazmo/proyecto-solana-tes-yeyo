## Specifications
### Application
This specification is for HTF piping 300# only.

### Service Range
- **Pressure / Temperature:** 350 PSIG / 750°F

### Materials
- **Pipe:** 304 SS pipe with SW fittings, CL 300 SW valves; BW fittings and CL300 BW valves; BW fittings
- **W.T. (0.500”):** 304 fusion welded SS in accordance with ASTM A-312, Grade TP304
- **Fittings:** Type 304 SS, Grade F304, ANSI B16.11; 304L SS, Grade WP304, BW, ANSI B16.9
- **Branch Conn.:** Use fittings for reduction, tee for full size thru two sizes smaller, sockolet or weldolet as required
- **Flanges:** 304 SS, ASTM A-182, Grade F304, Class 300 WN RF, ANSI B16.5 (use weld neck flange on BW fittings)
- **Bolting:** Alloy steel stud bolts, ASTM A-193 Grade B7 w/ heavy hex nuts, ASTM A-194 Grade 2H
- **Gasket:** 0.175” thick 304LSS and flexible graphite spiral wound gasket, API Standard 601 Class 600 (compresses to 1/8” thick)

### Notes
1. Welding Electrodes: Bare - AWS A5.9 Class ER 308, Coated - AWS A5.4 Class E 308-16, Carbon steel/stainless steel, Bare - AWS A5.9 Class ER 309.
2. Deleted
3. Weldolets or Sockolets are preferred for use at tie-in locations regardless of size change due to difficulty of realignment of piping after cutting.
4. Pressure / temperature allowed in this spec. are limited by F304 flange material. Do not substitute F304L, which has lower allowable pressure / temperature.
5. Gasket materials shall be 304L SS only. Do not substitute with 304SS.
