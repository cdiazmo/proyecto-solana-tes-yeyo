# Inspection & Test Plan

**Manufacturer:** RHEINHÜTTE Pumpen GmbH
**Project/Order:** TS 4521-ESP-AEPC-075-062-0002
**Client:** Arizona Solar One LLC

## Actions Quality Related
### 1. Check of Material Test Certificates and Dimensions of Incoming Parts
- **Reference Document:** R1 - R2 Review of Documentation
- **Characteristics to Be Verified:** Material: 1.7357 / 1.5415 and similar, EN 10204 3.1
- **Acceptance Criteria:** No defects
- **Verifying Document:** QA Manual, Internal parts Drawings, Chemical Composition of Volute Casing, Stage Casing, Suction Cover, Impeller, Shaft, Discharge Bend, Suspension Pipe, Support Column and Column Pipe

### 2. Liquid Penetrant Examination (PT) NDE Test Procedure
- **Reference Document:** ASME Section V
- **Characteristics to Be Verified:** Volute Casing, Suction Cover, Impeller, Welding’s of: Discharge Bend, Suspension Pipe
- **Acceptance Criteria:** No defects
- **Verifying Document:** Test Report A1 R1

### 3. Hydrostatic Test of Volute Casing, Suction Cover, Discharge Bend, Suspension Pipe
- **Reference Document:** Inspection and Test Procedure
- **Characteristics to Be Verified:** No defects
- **Acceptance Criteria:** Test Pressure: 12 bar, Test Duration: 30 min.
- **Verifying Document:** API 610 Test Report A1 R1

### 4. Balancing of Impeller
- **Reference Document:** Inspection and Test Procedure in double plane DIN ISO 1940-1 Grade 2.5
- **Characteristics to Be Verified:** Balancing
- **Acceptance Criteria:** No defects
- **Verifying Document:** Balancing Test Report A1 R1

### 5. Mechanical Running Test of Pump
- **Reference Document:** Inspection and Test Procedure
- **Characteristics to Be Verified:** No defects
- **Acceptance Criteria:** 4 hours at rated point with rated capacity, shop Motor and shop Coupling
- **Verifying Document:** Test Report A1 R1

### 6. Bearing Temperature Measurement Inspection and Test Procedure
- **Reference Document:** Inspection and Test Procedure
- **Characteristics to Be Verified:** Max. 82°C
- **Acceptance Criteria:** No defects
- **Verifying Document:** Test Report A1 R1

### 7. Noise Level Test Inspection and Test Procedure
- **Reference Document:** Inspection and Test Procedure
- **Characteristics to Be Verified:** Max. 85 dB(A) at a Distance of 1m
- **Acceptance Criteria:** No defects
- **Verifying Document:** Test Report A1 R1

### 8. Performance Test
- **Reference Document:** Inspection and Test Procedure with shop motor and shop coupling ISO 9906 Grade 2B
- **Characteristics to Be Verified:** No defects
- **Acceptance Criteria:** No defects
- **Verifying Document:** Test Report A1 R1

### 9. Vibration Test
- **Reference Document:** Inspection and Test Procedure during Performance Test ISO 5199
- **Characteristics to Be Verified:** No defects
- **Acceptance Criteria:** No defects
- **Verifying Document:** Test Report A1 R1

### 10. Final Visual and Dimensional Check (incl. Photos)
- **Reference Document:** approved GA Drawing
- **Characteristics to Be Verified:** Main Dimensions Tolerances of approved GA Drawing
- **Acceptance Criteria:** Approved GA Drawing
- **Verifying Document:** Check Certificate A1 R1

### 11. Painting Inspection: Dry Film Thickness (DFT) check, Painting System and finish colour check
- **Reference Document:** Painting Procedure
- **Characteristics to Be Verified:** Dry Film Thickness > 375 µm
- **Acceptance Criteria:** No defects
- **Verifying Document:** Test Certificate A1 R1
