# TES Exchangers Foundations Design

## Overview
The TES exchanger foundations of Solana Generating Station are designed.

## Description
The foundations consist of two reinforced concrete footings, each with an area of 49’2”x 11’6” and a thickness of 3 feet. Each footing has three reinforced concrete walls, each 14’7” high and 3’0” thick. The footings are buried 5 feet deep in engineered fill.

## References
- Report on Geotechnical Investigation by Abengoa Solar (Solana Power Plant)
- Speedie and Associates document, Project No. 0911985A, dated 12/21/09
- Hushmand Associates, Incorporated to Speedie and Associates, dated 06/21/2010
- Documents: 4521-PLN-FWE-21-52-0001, 4521-PLN-FWE-21-52-0002, 4521-PLN-FWE-21-52-0101, 4521-PLN-FWE-21-52-0001

## Codes and Normative
- IBC 2012 International Building Code
- ASCE 7-05 Minimum Design Loads for Buildings and Other Structures
- ACI-318 Building Code Requirements for Structural Concrete
- API 650 Welded Steel Tanks for Oil Storage

## Design Basis
A static finite elements analysis was performed using a beam elements frame to apply wind and earthquake loads. The soil has a sulfate concentration of 44 to 170 p.p.m., classified as S1, with chloride contents irrelevant due to water levels below grade.

## Ground Features
The ground bearing capacity is considered 3.000 psf. Test boring near the project area indicates an average number of blows per foot ranging from 25 to 30, resulting in a ground bearing capacity of about 2.850 – 3.400 psf.
