# 1950801-PLN-0040-00 Planificacion

## Resumen

- El proyecto se llama PLANTA HELIOS y está ubicado en Córdoba, España.
- Se han identificado varias tareas clave del proyecto, desde la ingeniería básica hasta el montaje final.
- La tarea de 'PLANTA HELIOS' comienza el 1 de enero de 2027 y termina el 1 de noviembre de 2028.
- El suministrador del paquete es LOINTEK, con el código de documento 1950801-PLN-0040-00.
- Tareas relacionadas con la construcción y operación de la planta termosolar Helios I y II.
- Involucran tareas como obra civil, estructura y accesos, piping y valvulería, instrumentación y control, y handover a la comisión.
- Las fechas de inicio y finalización están detalladas para cada tarea.
