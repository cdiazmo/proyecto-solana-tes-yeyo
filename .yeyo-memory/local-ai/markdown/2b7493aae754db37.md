# 4521-LIS-AEE-39-64-0002-GAR Rev.1 Automatic Valves List

## Resumen

- Document is for ABEINSA EPC USA project Solana TES HEX.
- Automatic Valve List document code: 4521-LIS-AEE-39-64-0002-GAR, reviewed by Jose María Rodríguez León.
- Changes in valves are indicated with red (removed), green (added), and yellow (modified) colors.
- Revisions control sheet shows two revisions: Dec/15/2016 and Jan/25/2017.
- General notes include instructions for updating revision numbers when changes occur.
- Document contains a list of automatic valves for the Solana Power Plant.
- Valves include gate and globe types, operated by hydraulic actuators.
- Valves are used in various systems such as HTF overflow, MS drain back, and TES HEX inlet.
- The document is part of the P&ID Rev Line Spec for ABEINSA EPC USA project.
- References include specific valve tags, models, and supplier data.
