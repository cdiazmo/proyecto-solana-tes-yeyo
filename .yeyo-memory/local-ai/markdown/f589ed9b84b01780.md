# 4521-CAL-AGE-75-52-0002 Rev 1-GAR

## Resumen

- Design and check of walls using SAP2000
- Vertical displacement of slab foundation checked at 1 inch
- Ground bearing pressure within acceptable limits
- Reinforcement design for walls and slabs
- Checks based on ACI-318 standards
- Tables for function-response spectrum analysis included

## Markdown estructurado

The document describes the design and check of different walls using SAP2000 calculation software. It includes diagrams for axial forces, shear force, bending moment, and vertical displacement of the slab foundation. The maximum allowable vertical displacement is 1 inch, with a calculated value of 0.105 inch. Ground bearing pressure is checked against values from a Geothecnical Report, with the case combination SLS Eq. 4C having a maximum value smaller than the ground bearing capacity. Reinforcement design for walls and slabs includes vertical and horizontal reinforcement, with checks based on ACI-318 standards. The document also includes tables for function-response spectrum analysis.
