# 4521-ESP-ANC-68-61-SS18

## Resumen

- This document specifies the material and installation standards for chemical feed piping systems, including pipe materials, fittings, flanges, bolting, gaskets, and valves. It also includes a pressure/temperature chart.

# Specification Form - Solana (Rev. 3/2011)

## Application
This specification is intended for chemical feed piping (chelating agents).

## Service Range
See Pressure / Temperature Chart on page 2 of 2.

## Construction
- **Pipe**: 304L SS pipe with buttweld flanges CL 1500 flanged valves (preferred) and CL 1500 socketweld valves.
- **Nominal Pipe Size**: Schedule 80, Schedule 160
- **Fittings**: Class 3000 socketweld, Class 6000 SW, Sch. 160 buttweld, 304L SS ASTM A-403
- **Flanges**: Socketweld Welding neck, 304L SS, ASTM A-182, Grade F304L, Class 1500, RF ANSI B16.5
- **Bolting**: Alloy steel stud bolts ASTM A-193 Grade B7 w/ heavy hex nuts ASTM A-194 Grade 2H
- **Gasket**: 0.175” thick 304 SS and flexible graphite spiral wound style CGI gasket, Class 1500, API Standard 601 (compresses to 1/8” thick)

## Valves
- **Gate Valve**: SA95 - CL 1500 SW, SA100 -CL 1500 RF flg.
- **Globe Valve**: SB95 - CL 1500 SW
- **Lift Check Valve (Hor. Use)**: SC95 - CL 1500 SW

## Notes
1. Welding Electrodes: Bare - AWS A5.9 Class ER 308, Coated - AWS A5.4 Class E 308-16, carbon steel/stainless steel, Bare - AWS A5.9 Class ER 309.
2. Sockolets or weldolets are preferred for use at tie-in locations regardless of size change due to difficulty of realignment of piping after cutting.
