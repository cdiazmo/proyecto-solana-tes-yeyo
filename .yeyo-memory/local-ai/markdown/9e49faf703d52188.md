## General
This specification sets forth acceptable standards of materials for miscellaneous insulation items. Miscellaneous insulation items shall be used to form and provide a complete insulation system.

## Materials
### Miscellaneous Item and Material Acceptable Vendors
- **Strapping Bands:**
  - ¾” wide x 0.020” (19 mm x 0.5 mm), type 304 S.S.
  - Acme Distributor Sales, ITW Insulation Systems, RPR Products Co.
- **Expansion Spring:**
  - Type 302 S.S., ITW Insulation Systems - Chil Spring
  - Heavy duty type 304 S.S., ITW Insulation Systems - Mity-Spring
- **Self-Tapping Screws:**
  - #8, type 304 S.S. with neoprene washers, No vendor preference

  - #14, type 304 S.S. with neoprene washers, No vendor preference

- **Speed Clips:** 2 ½” (64 mm) square, type 304 S.S.

- **Clips:** “S” Clips, “J” Clips, “J” Hooks, Bar Clips
- **Corner Caps:** 12” x 12” x 8 feet (305 mm x 305 mm x 2.4 m), 0.090” (2 mm) thick, fabricated aluminum
- **Rod:** ¼” (6 mm) Dia., type 304 S.S.
- **Spoiler Angles:** aluminum 2 ½’ x 2 ½” x 1/8” (64 mm x 64 mm x 3 mm)
