# 4521-PLN-LOI-039-062-0013-GAR rev00 TRANSPORT DRAWING

## Resumen

- The document contains confidential and restricted information.
- Equipment is shipped with nitrogen pressure of 0.5 bar (g).
- Hydrotest covers will be used for shipping.
- Paint orange all removable parts (HT caps and threaded plugs).
- Dimensions are in mm above and in inches below unless otherwise indicated.
- Use rubber pads on lifting marks if chains are used instead of nylon slings.
- Max angle for slings is 15°, with a maximum deviation angle of 5° in the longitudinal direction when using a yoke.
- The equipment weighs 232852 lb and has dimensions of ~575 17/64 in. x ~134 15/64 in. x ~109 9/64 in.
