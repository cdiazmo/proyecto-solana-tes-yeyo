# 1950801-DOC-4170-05 Espec. Tuberia

## Resumen

- El documento es una especificación técnica para tuberías y válvulas utilizadas en un proyecto de Central Termosolar SOLACOR 1&2.
- Se establecen presiones y temperaturas para el diseño de las tuberías.
- Los materiales de tubería y valvulería deben cumplir con ciertos requisitos según su especificación.
- Existen diferentes tipos de válvulas con materiales específicos dependiendo del Número de Trim.
- Se proporciona una tabla de control de revisiones para el documento.
- Especifica materiales para tuberías y válvulas.
- Incluye tipos de válvulas como compuertas, asientos, agujas, etc.
- Define presión-temperatura para diferentes ratings.
- Menciona componentes como juntas, esparragos y derivaciones.
- Contiene notas sobre uso y especificaciones adicionales.
- La especificación incluye detalles técnicos de válvulas y materiales para tuberías.
- Se mencionan diferentes tipos de válvulas como compuertas, asientos tipo T y Y, agujas, retención de pistón, doble disco, clapeta y bola.

## Observaciones

- El texto contiene errores tipográficos y inconsistencias en la nomenclatura de los materiales y especificaciones.
