# SS38 Engineering Standards and Practices

**Material and Installation Standards**
- **Job No.**: 120006
- **Project**: Solana
- **Ref. Issue**: 0, Dated: 19 Jul 11

**Service Range**: Pressure / Temperature - 350 PSIG / 750° F.

**Pipe Specifications**
| Nominal Pipe Size | Sch. 40S (PE) | Sch. 40S (BE) | Sch. 80S (BE) |
|-------------------|---------------|---------------|---------------|
| W.T. (0.500”)     | 304 fusion welded SS | 304L SS | 304L SS |

**Fittings and Valves**
- **CL3000 (SW)**: 304 SS, ASTM A-182, Grade F304, Class 300 WN RF, ANSI B16.5
- **TA40 - CL 300 SW**: Gate Valve
- **TA56 - CL 300 BW**: Gate Valve

**Bolting and Gasketing**
- **Bolts**: Alloy steel stud bolts, ASTM A-193 Grade B7 w/ heavy hex nuts, ASTM A-194 Grade 2H
- **Gaskets**: 0.175” thick 304LSS and flexible graphite spiral wound gasket, API Standard 601 Class 600

**Notes**
1. Welding Electrodes: Bare - AWS A5.9 Class ER 308, Coated - AWS A5.4 Class E 308-16, Carbon steel/stainless steel, Bare - AWS A5.9 Class ER 309.
2. Deleted
3. Weldolets or Sockolets are preferred for use at tie-in locations regardless of size change due to difficulty of realignment of piping after cutting.
4. Pressure / temperature allowed in this spec. are limited by F304 flange material. Do not substitute F304L, which has lower allowable pressure / temperature.
5. Gasket materials shall be 304L SS only. Do not substitute with 304SS.

- Butterfly Valves: N/A
- Plug Valves: N/A
