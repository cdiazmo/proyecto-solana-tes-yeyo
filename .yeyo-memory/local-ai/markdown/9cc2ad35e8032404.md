# 5.9.1.6 Formulario BT planta

## Resumen

- Solicitud de registro de proyecto general para una instalación BT en central termosolar Helios 1.
- Instalaciones incluyen seguridad contra incendios, eléctricas baja tensión y térmicas.
- Ubicación: Sevilla, España. Coordenadas UTM: X: 459015 / Y: 4343975.
- Potencia admisible de la instalación eléctrica de baja tensión: 11.483,4 kW.
- Normativa aplicable: RD 2135/1980 y Reglamentos Técnicos de Seguridad Industrial.
- Documentación aportar incluye escrito de comunicación, informes y certificados específicos.
- Certificados requeridos varían según el tipo de instalación (alta tensión, petrolíferas, frigorificas, equipos a presión).
- Instrucciones para cumplimentar formulario cubren definición de industria, indicación de características técnicas y requisitos de inspección inicial.
- Formulario requiere documentos específicos según el tipo de instalación y potencia instalada.
