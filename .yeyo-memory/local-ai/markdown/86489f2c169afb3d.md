# 4521-INF-AEE-21-63-0004-GAR TES HEX Change stress report

## Resumen

- Document title: TES HEX Change stress report
- Project: HEX replacement TES Solana
- Document number: 4521-INF-AEE-21-63-0004-GAR, Revision 00, Date: 30/01/2017
- Prepared by Juan Benítez Infante, reviewed by Miguel Trigueros González, approved by José María Rodríguez León
- Objective: Validate piping layout and define pipe supports for heat exchangers modification
- Scope includes calculation models for molten salts and HTF systems
- Contains sections on design conditions, allowable stresses, load combinations, inputs, results, and conclusions
- Design conditions include pressure, temperature, and wind loads.
- ASME B31.3 Process Piping is used for allowable stresses calculations.
- Load combinations are defined for various operating and design scenarios.
- Screen captures and input echoes are provided for reference.
- The document discusses stress ratings for various models.
