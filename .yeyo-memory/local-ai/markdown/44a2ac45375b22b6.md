# Engineering Standards and Practices
## Material and Installation Standards
**Job No.:** 120006
**Project:** Solana
**Material:** Class 600 Carbon Steel – Piping System
**Pressure/Temperature Chart (Figure No. 1) on Page 2 of 2**

### Notes:
1. All piping shall comply with ANSI B31.3 basic code unless otherwise specified.
2. Sockolets or weldolets are preferred for tie-in locations.
3. Flanges shall be used only where required to mate with equipment nozzles.
4. All pipe & fittings to be internally cleaned per spec 4521-ESP-ANC-00-61-PS010.
5. Shop and field root pass welds must use TIG welding process.
6. Shop welds require 5% X-ray, field welds require 100% X-ray.
7. All pipe shall be clean with no mill scale, slag, dirt, debris, or foreign objects.
