# Engineering Standards and Practices
## Material and Installation Standards
**Job No.:** 120006
**Class:** Class 300 Carbon Steel – Piping System
**Project:** Solana

### Service Range
Maximum 750 °F. See Pressure/Temperature Chart on Page 2.

### Construction Materials and Fittings
- **Pipe Size:** 22, 24, 30 inches
- **Wall Thickness:** 0.625”
- **Material:** Carbon steel, ASTM A-53 or API 5L Grade “B”, beveled ends
- **Fittings:** XXS Sch 160, Sch 120, XS Sch 40
- **Branch Connections:** Tee, Sockolet, Weldolet
- **Flanges:** FS CL 300, RTJ, weld neck ASTM A -105

### Bolting and Gasketing
- **Bolts:** Alloy steel stud bolts ASTM A-193 Grade B7 with heavy hex nuts ASTM A-194 Class 2H
- **Gaskets:** Low carbon steel/soft iron, ring joint, CL 300 RTJ, ASME B16.20, oval section

### Valves
- **Gate Valve:** FA58V - CL 300 buttweld
- **Globe Valve:** FB58V - CL 300 buttweld

### Notes
1. All piping shall comply with ANSI B31.3 basic code unless otherwise specified.
2. Sockolets or weldolets are preferred for tie-in locations.
3. Minimum pipe size in nitrate salt service is 2 inches.
4. All pipe & fittings to be internally cleaned per spec 4521-ESP-ANC-00-61-PS010.
5. Shop and field root pass welds shall use TIG welding process.
6. Pipe installation must be clean, free of mill scale, slag, dirt, construction debris, and foreign objects.
