# 5.10.1.7 Formulario LAAT parcial

## Resumen

- Solicitud de autorización para instalación eléctrica de alta tensión.
- Instalación de línea aérea de 220 KV para evacuar energía solar termoeléctrica.
- Presupuesto de dos millones setenta y siete mil euros.
- Finalidad: Evacuación de energía desde una planta solar termoeléctrica hasta una subestación en la zona afectada del proyecto.
- Datos del titular y representante incluidos.
- Declaración bajo responsabilidad por los datos proporcionados.
- Competencia del Director/a General y Delegado/a Provincial de Industria, Energía y Medio Ambiente.
- Documentación común a todas las solicitudes incluye DNI, proyecto básico, justificación de capacidad legal y económica, autorización administrativa, etc.
- Se requiere la presentación de documentos como el proyecto técnico, memoria técnica, certificado de dirección, etc.
- Notas informativas sobre protección de datos personales y plazos para tramitación del procedimiento administrativo.
