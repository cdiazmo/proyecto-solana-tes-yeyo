## Specifications
### Application
This specification is for propane piping only (liquid or vapor).

### Service Range
- **Pressure/Temperature:** 285 PSIG / -20°F to 100°F, 195 PSIG / 750°F (Max.), Valves 350°F Max.

### Construction Materials
- **Pipe:** Carbon steel pipe, socketweld, FS fittings, flanges and valves, CL 150 RF flanged valves
- **Nominal Pipe Size:** 1/2, 3/4, 1, 1 1/2, 2, 3
- **Piping Material:** Carbon steel, seamless, Schedule 80, ASTM A-53 or ASTM A-106 Grade “B”, plain end
- **Fittings:** CL 3000 FS, SW, ASTM A-105
- **Coupling:** CL 3000 FS, SW, ASTM A-105
- **Union:** CL 3000 FS, SW, ASTM A-105, steel to steel seats
- **Branch Conn. Use Fittings:** For reduction use inserts
- **Flanges:** FS CL 150, SW, RF, ASTM A-105, ANSI B16.5
- **Bolting:** Alloy steel stud bolts ASTM A-193 Grade B7 w/ heavy hex nuts AST M A-194 Class 2H
- **Gasket:** 0.175” thick 304 SS and flexible graphite spiral wound gasket Class 150 API -601

### Valves
- **Gate Valve:** FA37 - CL 800 socketweld
- **Plug Valve:** FE42Z - CL 150 RF flanged
- **Globe Valve:** FB37 - CL 800 socketweld
- **Ball Valve:** FF34 - CL 300 socketweld
- **Swing Check valve (Vert. or Hor. Use):** FC37 - CL 800 socketweld

### Welding Electrodes
- **Bare:** AWS A5.18 Class E605-2
- **Coated:** AWS A5.1 Series E60

### Notes
Valves must be located in a position well back from burner face or other possible sources of high temperature transmitted to piping systems using this specification.
