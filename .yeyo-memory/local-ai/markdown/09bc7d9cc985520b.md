## Gate Valves: Specification
- **CA11**: Class 175 MJ, 4"-12", Cast iron gate valve, bolted bonnet, inside screw, non-rising stem, bronze stem, stem nut, seat and solid wedge disc, gaskets, packing bolting and other possible trim to be UL approved.
- **CA12**: Class 175 MJ, 4" - 12", (Indicator Post), Cast iron gate valve, bolted bonnet, inside screw, non-rising stem, bronze stem, stem nut, seat and solid wedge disc, gaskets, packing bolting and other possible trim to be UL approved.
- **CA40**: Class 125 FF flanged, 3" - 48", (gear operator 24" and above), Cast iron gate valve, bolted bonnet, inside screw, non-rising stem, bronze stem, cast iron double disc with bronze rings, manganese bronze stem, bronze renewable seat, rubber o-ring packing, valve box, cover and stem.
- **CA42**: Class 125 M J flanged, 3" - 30", (gear operator 24" and above), Cast iron gate valve, bolted bonnet, inside screw, non-rising stem, cast iron double disc with bronze rings, manganese bronze stem, bronze renewable seat, rubber o-ring packing, valve box, cover and stem.
## Hydrant Valves: Specification
- **CB11**: Class 150 MJ, 6"inlet, Cast iron hydrant valve, break flange, 5 ¼” main valve opening, with two 2½” hose nozzle and one 4 ”pumper nozzle, bronze stem, seat and disc, national standard pentagon nut, hydrant wrench, hose and pumper nozzle threads per UL and FM gaskets packing, bolting and other possible trim to be UL approved.
## Check Valves: Specification
- **CC11**: Class 175 MJ, 4" - 12", Cast iron swing check, bolted cover, bronze disc and seat, gaskets, packing, bolting and other possible trim to be UL approved.
