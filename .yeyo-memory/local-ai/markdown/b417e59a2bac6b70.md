# 1950801-LIS-6000-00 Rev.01 Lista de Instrumentos

## Resumen

- Lista de instrumentos con diferentes tipos y ubicaciones.
- Incluye transmisores de temperatura y nivel.
- Todos los dispositivos tienen la misma protección IP65.
- Se utilizan materiales como sal fundida, tanque de fundición y nitrógeno/HTF.
- Hay una variedad de grupos (G10 a G15) asociados con diferentes ubicaciones.
