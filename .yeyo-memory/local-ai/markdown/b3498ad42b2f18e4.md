# Engineering Standards and Practices Document No: 4521-ESP-ANC-68-61-PL15
## Material and Installation Standards Job No.: 120006
### CPVC – Piping System Project: Solana
#### Service Range:
- Pressure: 80 PSIG Maximum (See Note 1)
- Temperature: 140° F. Maximum (See Note 2)
#### Materials:
- CPVC Pipe, S.W.
- CPVC fittings and flanges
- TFE or Polypropylene lined and CPVC valves
#### Specifications:
- Nominal Pipe Size: 1/2", 3/4", 1", 1 1/2", 2", 3", 4", 6", 8", 10"
- Schedule 80 CPVC, Plain End, Type 4, Grade 1
- Nipple Use Pipe Fittings
- Coupling: Same as Fittings above
- Union: Use Flanges
- Branch Connection: Use Fittings, for reductions use S.W. Reducing Insert Flanges
- Bolting: Carbon Steel ASTM A-307 Grade B Bolts With Heavy Hex Nuts & Washers (See Note 5)
- Gasket: 1/8” Butyl Rubber Full Face Gaskets, 50-70 Shore A durometer hardness
#### Valves:
- Ball Valve: PCF25 - 150# S.W. (CPVC) TFB43 - 150# Flanged
- Lift Check Valve: Vert. Use, Horz. Use
- QPC444 - 150# RF Flanged
- Ball Check Valve: Vert. or Horz. Use
- PCC25 - 150# S.W. (CPVC)
- QPC42 - 150# RF Flanged
#### Notes:
1. Maximum working pressure in PSIG for Pipe Size: 1/2” 3/4” 1” 1 1/2” 2” 3” 4” 6” 8”
2. CPVC material becomes brittle at temperatures below 40 ° F.
3. Use TFE tape for threaded connections.
4. Clean socketweld joints with manufacturer’s recommended primer before solvent cement application.
5. Use washers per ANSI B18.22.1, Table 1A Size N (Narrow)
