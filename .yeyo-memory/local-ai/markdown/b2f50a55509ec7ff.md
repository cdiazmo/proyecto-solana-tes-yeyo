## Codes and Normative
- IBC 2012 International Building Code
- AISC 360-10 American Institute steel code
- ASCE 7-05 Minimum Design Loads for Buildings and Other Structures.

## Design Basis
For design purpose a static finite elements analysis have been performed using a shell elements in order to apply the different loads. The materials used are:
- Structural steel W-shape: ASTM A992 (Fy=50 ksi)
- Other structural steel : ASTM A36
- Bolted connections high strength: ASTM A325 or A490
- Secondary bolts: ASTM A307

The safety factors and load combination coefficients are:
- Fracture U.L.S. rolled steel: ANSI/AISC 360-05 (LRFD)

The loads applied are:
- Dead load - Specific self-weight of steel elements: 490 lb /ft³
- Self-Weight of Drain tank: 6,500 lb
- Self-Weight of pump: 500 lb
- Live Load - Weight water in maximum capacity of tank: 13,000 lb
