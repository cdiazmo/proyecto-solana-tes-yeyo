# 1950801-LIS-3660-00 Rev01 Lista Valvulas General-260428

## Resumen

- Sheet name: SPReport_Definition
- Columns include Plant Item, Representation, Drawing, and Drawing Project
- Data includes project details like Yanbu, KKSEquipmentUnitKey, and EA_KKSDrawingNumber
- Represents various valve types and their specifications
- Includes technical details such as power rating, material, and fluid compatibility
- Lista de válvulas con detalles técnicos.
- Válvulas incluyen tipos como GATE, BUTTERFLY, CHECK, GLOBE, NEEDLE y BALL.
- Norma utilizada es ASTM A105 para todas las válvulas.
- Presión varía entre 150 Lb y 800 Lb.
- Temperatura constante en 25°C para la mayoría de las válvulas.
- Fluidos incluyen HTF, MOLTEN SALTS, Nitrogen y otros.
- Modos de control son Motor, Pneum y Manual.

## Observaciones

- Algunos datos como 'Medida' y 'Referencia' están incompletos.
