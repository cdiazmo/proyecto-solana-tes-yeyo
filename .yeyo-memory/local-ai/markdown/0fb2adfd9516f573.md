# 4521-ESP-ANC-68-61-SS19
## Engineering Standards and Practices Document
### Material and Installation Standards
**Job No.:** 120006
**Doc Code:** 4521-ESP-ANC-68-61-SS19
**Revision:** -
**Deliverable Part:** Pliego de condiciones
**Discipline:** Proceso / mecanica / tuberias

### Application
This specification is intended for boiler feedwater and condensate.

### Service Range
**Pressure / Temperature**
- Boiler Feedwater: 150 PSIG / 400 ° F (Max.)
- Condensate: 200 PSIG / 250 ° F (Max.)

### Construction
316 SS tubing with compression fittings and CL 600 tubing end valves.

### Tubing Wall Thickness
| Nominal Tubing O.D. | Tubing Wall Thickness |
|---------------------|-----------------------|
| 1/4 NPS               | .028                  |
| 3/8 NPS               | .035                  |
| 1/2 NPS               | .049                  |
| 5/8 NPS               | .065                  |
| 3/4 NPS               | .083                  |

### Fittings and Valves
- **Compression type:** 316 SS forging or bar stock as mfg'd by “Gyrolok”, “Swagelok”, “Tylok”
- **Branch Conn.:** Flanges (316 SS, ASTM A-182, Grade F316, Class 600 threaded RF ASME B16.5)
- **Stub Ends:** Galvanized alloy steel stud bolts, ASTM A-193 Grade B7, heavy hex nuts ASTM A-194, Grade 2H
- **Gasket:** 1/8” thick ring type, Garlock Gylon 3510

### Ball Valve
TF4 - Tubing end valve

### Plug Valve
TE3 – Tubing end valve

### Needle Globe Valve
TB4 – Tubing end valve

### Swing Check Valve
(vert. or hor. Use) TC5 - Tubing end valve (lift check – horizontal flow)

### Notes
1. Buttweld piping system intended to be used for connecting to equipment.
2. Minimum bend radius for tubing in this specification is 2x outside tube diameter.
3. Pressure / temperature allowed in this spec. are limited by F316 flange material.
4. All material in this spec is intended to be designed, fabricated and purchased in the field.
