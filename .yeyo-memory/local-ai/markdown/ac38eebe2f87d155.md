# Drain Back Tank Pit Design

## Overview
The Drain Back tank pit of Solana Generating Station is designed.

## Description
- **Shape and Dimensions**: The pit has dimensions of 24’11”x 15’9”, with an inner height of 10’6” and a slab thickness of 3’0”.
- **Support**: Supported over subbase by filling with suitable material (type A1 or A3 compacted 95% according to AASTHO T1-180).
- **Steel Structure**: Anchored by several post-installed bolts on the slab.

## References
- Report on Geotechnical Investigation. Abengoa Solar (Solana Power Plant)
- Speedie and Associates document, Project No. 0911985A
- Hushmand Associates, Incorporated to Speedie and Associates
- Loads from documents: 4521-PLN-FWE-21-52-0001, 4521-PLN-FWE-21-52-0002, 4521-PLN-FWE-21-52-0101, 4521-PLN-FWE-21-52-0001

## Codes and Normative
- IBC 2012 International Building Code
- ASCE 7-05 Minimum Design Loads for Buildings and Other Structures
- ACI-318 Building Code Requirements for Structural Concrete
- API 650 Welded Steel Tanks for Oil Storage

## Design Basis
A static finite elements analysis using shell elements has been performed to apply different loads. Materials chosen based on the Geotechnical Report include:
- **Concrete**: 4000 psi, water-cement relation W/CM ≤ 0.5, Type II cement
- **Steel**: Grade 60
