# TES Exchangers Foundations Design

## Overview
The TES exchanger foundations at the Solana Generating Station are designed to support the equipment.

## Description
- **Shape and Dimensions**: Two reinforced concrete footings, each with an area of 49’2” x 11’6” and a thickness of 3 feet. Each footing has three reinforced concrete walls, each 14’7” high and 3’0” thick.
- **Buried Depth**: Projected to be buried down 5 feet of engineered fill according to design instructions.

- Report on Geotechnical Investigation by Abengoa Solar (Solana Power Plant)

- Load documents: 4521-PLN-FWE-21-52-0001, 4521-PLN-FWE-21-52-0002, 4521-PLN-FWE-21-52-0101, 4521-PLN-FWE-21-52-0001

## Codes and Normative
- IBC 2012 International Building Code
- ASCE 7-05 Minimum Design Loads for Buildings and Other Structures
- ACI-318 Building Code Requirements for Structural Concrete
- API 650 Welded Steel Tanks for Oil Storage

## Design Basis
- **Materials**: Concrete (4000 psi, W/CM ≤ 0.5, Type II cement), Steel (Grade 60)
- **Ground Features**: Ground bearing capacity considered as 3.000 psf; Test boring near the area shows an average number of blows per foot between 25 to 30 b/ft.
